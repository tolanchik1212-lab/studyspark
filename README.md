StudySpark — AI Tools for Students

A responsive landing page showcasing five AI tools that can help students learn, research, and organize their studies.

Live Demo

"Open StudySpark" https://tolanchik1212-lab.github.io/studyspark/

Features

- Five AI tool cards: ChatGPT, Perplexity, Gemini, NotebookLM, and Claude
- Responsive layout for desktop and mobile devices
- Light and dark themes
- Clean, modern user interface
- Simple navigation and interactive elements

Built With

- CSS3
- JavaScript
