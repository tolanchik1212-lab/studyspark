# StudySpark — Топ-5 ИИ для учёбы

Одностраничный адаптивный сайт на HTML, CSS и JavaScript без фреймворков.

## Запуск
1. Распакуйте архив.
2. Откройте `index.html` в браузере.
3. Для публикации загрузите `index.html` на любой статический хостинг (например, GitHub Pages или Netlify).

## Возможности
- Переключение светлой и тёмной темы с сохранением выбора.
- Адаптивная сетка для компьютеров, планшетов и телефонов.
- Меню для мобильных экранов.
- Оптимизированные CSS-анимации и отложенная загрузка изображений карточек.
- Семантическая HTML-разметка, подписи для доступности и учёт настройки уменьшения анимации.

## Примечания
Шрифты и фотографии загружаются из внешних источников, поэтому для их отображения нужен интернет. Ссылки на ИИ-сервисы открываются в новой вкладке. Проверьте актуальность доступности сервисов и тарифов перед публикацией.
